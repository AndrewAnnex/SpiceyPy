=======
Gallery
=======

Worked examples of SpiceyPy, each one a complete script you can run in this
browser page. Every code cell on an example page is a live editor running
SpiceyPy on `Pyodide <https://pyodide.org/en/stable/>`_: hover over a cell
and click the run arrow, and edit the code to try your own ideas. Cells on a
page share one Python session, so run them in order. The output shown beneath
each cell was produced when these docs were built, and is replaced when you
run the cell yourself.

The first run on a page downloads Pyodide, the packages and that example's
SPICE kernels, so it can take a little while. Each example can also be
downloaded as a Python script or Jupyter notebook. These are written for the
browser, so to run one locally, download the kernels listed in its page's
PyScript config and swap ``display(fig, ...)`` for ``plt.show()``.
